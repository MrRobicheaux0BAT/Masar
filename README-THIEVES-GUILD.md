# Masar — Skyrim Companion

GitHub Pages site with three modes:

- **Thieves Guild** — radiant job tracker, unlock brackets, Stones of Barenziah checklist
- **Lore Library** — era map, lore threads, and brief summaries for Skyrim books
- **Quests** — full quest codex by mother category (Main, Companions, College, Thieves Guild, Dark Brotherhood, Civil War, Daedric, Dawnguard, Dragonborn, side quests by hold). Tap a quest for how to start it, alternatives, and fail states. ALT markers cover exclusive paths (e.g. kill Astrid → Destroy the Dark Brotherhood).

Live: https://mrrobicheaux0bat.github.io/Masar/

Progress is stored in browser `localStorage` (guild job keys unchanged when lore/quests tabs were added).

Data sources: [UESP Lore:History](https://en.uesp.net/wiki/Lore:History), [UESP Skyrim:Books](https://en.uesp.net/wiki/Skyrim:Books), [UESP Skyrim:Quests](https://en.uesp.net/wiki/Skyrim:Quests).
