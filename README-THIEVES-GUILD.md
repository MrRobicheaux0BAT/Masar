# Masar — Thieves Guild Tracker & Lore Library

GitHub Pages site with two modes:

- **Thieves Guild** — radiant job tracker, unlock brackets, Stones of Barenziah checklist
- **Lore Library** — era map, lore threads, and brief summaries for Skyrim books

Live: https://mrrobicheaux0bat.github.io/Masar/

Progress is stored in browser `localStorage` (job keys unchanged when the lore tab was added).

Data sources: [UESP Lore:History](https://en.uesp.net/wiki/Lore:History), [UESP Skyrim:Books](https://en.uesp.net/wiki/Skyrim:Books).
